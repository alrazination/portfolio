Close the loop

The linear economy is a conveyor belt: take, make, waste. In this arcade game, learners have seconds to rescue materials before they burn, and must find the machine that gives each one a second life.

Audience
Young learners
Topic
Upcycling and the circular economy
Core mechanic
Rescue items from a moving belt
Built with

Play it

Drag each item off the belt and into the machine that can upcycle it, before it reaches the incinerator.

Open full screen

Built for a mouse or touchscreen at laptop size or larger. On a phone, open it full screen and turn your phone sideways.

Where it started

"Linear economy" and "circular economy" are abstract ideas. Learners can repeat the definitions without ever feeling the difference.

A conveyor belt that feeds an incinerator makes the linear economy literal: things move one way and end up as smoke. The only way to stop it is to act, and to know what each material can become.

The core mechanic

Items ride the belt toward the fire. Learners drag each one into one of three machines in the Il Vespaio Eco-Design Maker Space, and the right machine turns waste into a new product.

Designing the mistakes

Design decisions

Time pressure with a reason

The belt keeps moving because the linear economy doesn't wait. Burned items come round again, so nobody gets stuck.

Show the product

Each machine shows what it makes, so learners connect a material to its next life.

A score that means something

The circularity score measures how much was kept in the loop, not how fast you clicked.

Celebrate every rescue

Each save gets a sound, sparks and a "PING!". Small rewards keep younger players going.

How it's built

CSS animationInline SVGWeb Audio APIPointer events

Machines, belt and effects are CSS and inline SVG. Every sound is generated in the browser with the Web Audio API, so there are no audio files to load.
